## v0.9.2 변경 사항

- 같은 Wi-Fi/LAN에서 상대방이 안 보이던 문제를 완화했습니다. macOS는 로컬 네트워크 접근 권한 요청에 설명 문구가 뜨도록 했고, Windows는 설치 시 방화벽 예외를 자동으로 등록합니다 (설치 프로그램이 관리자 권한을 요청합니다).
- 자동 업데이트용 업로드 파일명이 잘못 생성되던 문제를 수정했습니다.
- 다운로드 페이지에 SignPath Foundation 코드 서명 지원 안내를 추가했습니다.

## 다운로드

- macOS: `Overlay Lupin-0.9.2-universal.dmg` (Apple Silicon·Intel 공용)
- Windows: `Overlay Lupin Setup 0.9.2.exe`

(그 외 `.zip`, `.blockmap`, `.yml` 파일은 자동 업데이트용 내부 파일이니 무시하셔도 됩니다)
