## v0.9.4 변경 사항

- 점프맵을 정상 구간까지 확장하고 좁은 발판과 빠른 이동 발판을 추가했습니다.
- 저층 통나무, 중층 바위, 고층 구름 형태의 연필 스케치 블록으로 개선했습니다.
- ↑ 방향키 점프, 스페이스바 공격으로 조작을 변경했습니다.
- 더블점프를 제거하고 낙하 시 맨 아래 시작점에서 다시 시작하도록 변경했습니다.

## 다운로드

- macOS: `Overlay Lupin-0.9.4-universal.dmg` (Apple Silicon·Intel 공용)
- Windows: `Overlay Lupin Setup 0.9.4.exe`

(그 외 `.zip`, `.blockmap`, `.yml` 파일은 자동 업데이트용 내부 파일입니다.)

## v0.9.3 변경 사항

- macOS Info.plist에 `NSBonjourServices`를 추가해, 일부 환경에서 Finder로 실행 시 로컬 네트워크 권한 프롬프트가 뜨지 않는 macOS 자체 버그에 대한 완화를 시도했습니다 (완전한 해결책은 아닐 수 있습니다).

## 다운로드

- macOS: `Overlay Lupin-0.9.3-universal.dmg` (Apple Silicon·Intel 공용)
- Windows: `Overlay Lupin Setup 0.9.3.exe`

(그 외 `.zip`, `.blockmap`, `.yml` 파일은 자동 업데이트용 내부 파일이니 무시하셔도 됩니다)
