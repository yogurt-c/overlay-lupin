## v0.12.1 변경 사항

- 점프맵에 개인 최단 완주 기록을 추가했습니다. 플레이 중 현재 시간과 개인 최고기록을 표시하고, 완주하면 기록과 신기록 단축 시간을 안내합니다.
- 혼자하기와 같이하기 기록은 각각 저장됩니다. 같이하기에서도 자신의 개인 최고기록을 확인할 수 있습니다.
- 기록은 앱의 사용자 데이터 폴더에 저장되어 앱을 껐다 켜도 유지됩니다. 기존 브라우저 저장소에 남아 있는 기록은 자동으로 옮기며, 저장 실패 시 화면에 안내합니다.
- 맵 로딩 시간은 기록에서 제외하고 추락 후에도 시간은 계속 누적됩니다. 같이하기 완주 시간은 방장이 확정한 값을 사용합니다.

같이하기에서 완주 시간과 개인 기록을 사용하려면 방장도 v0.12.1으로 업데이트해 주세요.

## 다운로드

- macOS: `Overlay-Lupin-0.12.1-universal.dmg` (Apple Silicon·Intel 공용)
- Windows: `Overlay-Lupin-Setup-0.12.1.exe`

그 외 `.zip`, `.blockmap`, `.yml` 파일은 자동 업데이트용 파일입니다.
