## v0.11.1 변경 사항

- 업데이트 안내를 별도 창 대신 오버레이 안에서 보여 줍니다.
  - 새 버전이 나오면 백그라운드에서 받고, 왼쪽 아래에 진행률을 표시합니다. 다 받으면 **재시작** 버튼으로 바로 적용하거나, 다음에 앱을 종료할 때 자동으로 적용됩니다.
  - 받기에 실패하면 **다시 시도** 버튼이 나타납니다.
  - 게임 중에는 알림이 숨겨졌다가 게임이 끝나면 다시 나타납니다.
- 설정 패널에서 현재 버전을 확인하고 **업데이트 확인**으로 직접 새 버전을 찾을 수 있습니다.

v0.11.0에서 이 버전으로 올라갈 때는 기존 업데이트 창이 마지막으로 한 번 더 표시됩니다.

## 다운로드

- macOS: `Overlay-Lupin-0.11.1-universal.dmg` (Apple Silicon·Intel 공용)
- Windows: `Overlay-Lupin-Setup-0.11.1.exe`

그 외 `.zip`, `.blockmap`, `.yml` 파일은 자동 업데이트용 파일입니다.
